


# 卫星遥感常见载荷

卫星遥感是指通过运行在地球轨道上的航天器，利用其搭载的传感器（即“载荷”）收集地球表面或大气的电磁波信息，从而实现对地球系统的观测。遥感载荷是卫星的“眼睛”，其性能直接决定了遥感数据的质量和应用价值。根据其获取信号的来源，遥感载荷主要分为**被动遥感载荷**（接收目标反射的太阳光或自身发射的热辐射）和**主动遥感载荷**（自身发射电磁波并接收目标的回波）。

----------

## 一、被动遥感载荷 (Passive Sensors)

被动传感器不发射电磁波，而是被动接收来自地球表面或大气反射的太阳辐射，或者地球自身发射的热辐射。

### 1. 多光谱/全色光学相机 (Multispectral / Panchromatic Optical Imagers)

-   **功能：** 获取地表高分辨率的二维视觉图像。全色相机获取单一宽波段的黑白高分辨率图像；多光谱相机获取几个到十几个特定窄波段（如红、绿、蓝、近红外）的彩色/伪彩色图像，用于地表覆盖分类、植被长势监测、城市规划、水体分布制图等。

 <p align="center"><img src="https://raw.githubusercontent.com/amariszhou/desksat/main/solarpanel/image11.png" /><br>图 1 桌面星用相机 </p>       

    
-   **物理与技术原理：**
    
    -   **光学成像：** 地表物体反射太阳光，不同材质的物体对不同波长光线的反射率不同（即光谱特征）。光学镜头收集这些反射光并将其聚焦在焦平面上。
        
    -   **光电转换：** 焦平面上安装有光电探测器（如CCD电荷耦合器件或CMOS互补金属氧化物半导体）。当光子打在探测器像元上时，由于光电效应，光子能量转化为电子，积累的电荷量与入射光强成正比。
        
    -   **推扫式成像 (Pushbroom Scanning)：** 现代卫星多采用线阵推扫式成像。卫星在轨道上飞行，线阵探测器垂直于飞行方向排列，卫星每向前飞行一步，探测器就采集一行数据，随着卫星的运动，像“扫帚”一样扫出一条连续的二维图像带。
        
-   **代表卫星：** 美国的 Landsat 系列、WorldView 系列，欧洲的 Sentinel-2，中国的高分系列（GF-1, GF-2）。
        

### 2. 高光谱成像仪 (Hyperspectral Imagers)

-   **功能：** 精细识别地物材质。与多光谱的“宽频”不同，高光谱相机可以获取几十个甚至数百个连续、极窄波段的光谱数据。它可以识别特定的矿物成分、区分不同种类的农作物、监测水体中的特定污染物（如叶绿素a浓度、悬浮物），甚至识别伪装目标。
    
-   **物理与技术原理：**
    
    -   **色散分光：** 核心原理是将进入相机的复合光通过色散元件（如棱镜或衍射光栅）分解成连续的单色光光谱。
        
    -   **数据立方体 (Data Cube)：** 探测器不仅仅记录空间信息（X, Y），还记录光谱信息（λ）。最终生成的是一个三维的数据立方体，图像中的每一个像素点都包含一条连续且完整的反射率光谱曲线。这条曲线就像是物质的“指纹”，通过比对已知物质的光谱库，可以实现从“看形状”到“认材质”的跨越。
        
-   **代表卫星：** 美国的 EO-1 (Hyperion 载荷)，欧洲的 PRISMA，中国的高分五号 (GF-5)。

### 3. 热红外成像仪 / 辐射计 (Thermal Infrared Imagers)

-   **功能：** 测量地表或云顶的温度分布。常用于城市热岛效应监测、森林火灾早期预警与火点追踪、火山活动监测、洋流分析（海表温度SST）以及旱情监测（通过地表蒸散发反演）。
    
-   **物理与技术原理：**
    
    -   **热辐射定律：** 任何绝对温度大于零度（0 K）的物体都会不断向外发射红外辐射。根据普朗克定律和斯忒藩-玻尔兹曼定律，物体发射的热辐射强度与其温度的四次方成正比。
        
    -   **大气窗口：** 热红外载荷通常工作在 8-14 微米的大气窗口（这一波段的红外线受大气吸收影响较小）。
        
    -   **探测器：** 采用特殊的热敏材料或光电材料（如碲镉汞 HgCdTe），由于热红外光子能量较低，高端热红外载荷通常需要配备深冷制冷机（如斯特林制冷机）将探测器冷却至极低温度（如 77K 左右），以消除仪器自身的暗电流和热噪声干扰。
        
-   **代表卫星：** Landsat-8/9 (TIRS 载荷)，Aqua/Terra (MODIS 载荷)，NOAA 系列。
    
        

### 4. 微波辐射计 (Microwave Radiometers)

-   **功能：** 测量大气、陆地和海洋表面的微波辐射特征。它可以穿透云层，实现全天候观测。主要用于反演土壤水分、海洋盐度、海冰覆盖率和厚度、以及大气中的水汽和液态水含量。
    
-   **物理与技术原理：**
    
    -   **微波热辐射：** 地球物质除了发射红外辐射，也会发射微弱的微波频段辐射。由于微波波长较长（毫米到分米级），其能量极其微弱。
        
    -   **亮温 (Brightness Temperature)：** 微波辐射计测量的是目标的“亮温”，这不仅与目标的物理温度有关，更强烈依赖于物质的介电常数（如土壤中的含水量极大地改变介电常数）和表面粗糙度。
        
    -   **高灵敏度接收：** 为了捕捉极其微弱的自然微波信号，该载荷配备了巨大的天线（有时直径达数米甚至十几米，如SMAP卫星）和极高灵敏度、低噪声的微波接收机。
        
-   **代表卫星：** 美国的 SMAP（土壤水分主被动卫星），ESA 的 SMOS（土壤水分和海洋盐度卫星），中国的风云气象卫星系列。

## 二、主动遥感载荷 (Active Sensors)

主动传感器自带“闪光灯”，它们主动向地球发射电磁波脉冲，然后接收并分析从目标反射回来的回波信号。最大的优势是**不受昼夜和恶劣天气的限制（全天时、全天候）**。

### 1. 合成孔径雷达 (Synthetic Aperture Radar - SAR)

-   **功能：** 获取地表高分辨率微波图像。由于微波能够穿透云雾甚至部分穿透干旱土壤和植被，SAR 成为灾害应急（洪水、地震）、形变监测（地表沉降、滑坡）、海上目标检测（船只、溢油）、冰川移动监测的神器。
    
-   **物理与技术原理：**
    
    -   **主动测距：** 雷达天线侧视（倾斜向一侧）发射微波脉冲。通过测量脉冲发出到返回的时间差，可以极其精确地确定目标的斜距。
        
    -   **合成孔径原理 (Synthetic Aperture)：** 根据天线理论，雷达的方位向（飞行方向）分辨率与天线长度成反比。要在太空获得高分辨率，需要长达几千米的物理天线，这在工程上不可能实现。SAR 的绝妙之处在于：利用卫星的高速飞行，在飞行的不同位置对同一个目标连续发射和接收脉冲。通过复杂相干信号处理，将这一系列短天线接收到的信号在相位上对齐并叠加，从而在数学上“合成”一个长达几公里的虚拟超级大天线，极大地提高了方位向的分辨率。
        
    -   **极化与干涉 (InSAR)：** SAR 不仅测量回波强度，还记录电磁波的相位。利用同一地区不同时间获取的两幅 SAR 图像进行相位干涉（InSAR技术），可以测量出毫米级至厘米级的地表微小形变。
        
-   **代表卫星：** 欧洲的 Sentinel-1，加拿大的 RADARSAT，中国的高分三号 (GF-3)。

### 2. 激光雷达 (LiDAR - Light Detection and Ranging)

-   **功能：** 精确测量目标的三维高程结构。在航天领域，主要用于测量全球地形高程、冰盖厚度变化、森林树冠高度（生物量估算）、以及大气气溶胶和云层的垂直分布（大气轮廓）。
    
-   **物理与技术原理：**
    
    -   **飞行时间测距 (Time of Flight - ToF)：** 激光雷达向地表发射极短的激光脉冲（通常在近红外或绿光波段）。光以光速传播，通过精确计时器记录激光发射和接收到回波的时间差 ($t$)，利用公式 $Distance = (c \times t) / 2$ 即可计算出极其精确的高程距离。
        
    -   **全波形记录：** 对于森林植被，激光脉冲穿过树冠时，树叶、树枝和地面会分别产生回波。先进的星载 LiDAR 能够记录整个回波脉冲的波形（Full-waveform），通过分析波形的波峰分布，能够立体地反演出森林的垂直结构和高度。
        
    -   **大气散射：** 用于大气观测的 LiDAR 会分析大气分子、气溶胶对激光的后向散射信号，从而获取大气的垂直剖面特征。
        
-   **代表卫星：** 美国的 ICESat-2 (冰雪与地形高程卫星)，GEDI (国际空间站上的全球生态系统动力学调查载荷)，中国的陆地生态系统碳监测卫星“句芒号”。

### 3. 雷达高度计 (Radar Altimeter)

-   **功能：** 精确测量星下点的地球表面高度。这是海洋学研究的基石，用于测量海平面异常、大洋环流、海浪有效波高、以及极地冰盖的地形。
    
-   **物理与技术原理：**
    
    -   **垂直测距：** 与侧视的SAR不同，高度计直接向正下方发射宽带微波脉冲。
        
    -   **波形分析：** 接收到的回波波形反映了表面的特性。对于平静海面，回波上升沿很陡；对于粗糙海面，回波前沿变缓。通过分析回波的前沿中点时间，可精确计算海面高度；通过分析回波前沿的斜率，可以反演出海浪高度。
        
    -   **精密定轨：** 要获得精确的海面高度（相对于参考椭球），必须极其精确地知道卫星自身在空间的位置。因此高度计载荷必须配合精密定轨系统（如 GPS、DORIS 和激光反射镜）共同工作。
        
-   **代表卫星：** 欧美的 Jason 系列（如 Jason-3, Sentinel-6），中国的中法海洋卫星 (CFOSAT)、海洋二号系列 (HY-2)。
    
        

### 4. 微波散射计 (Microwave Scatterometer)

-   **功能：** 大面积测量海面风场（风速和风向）。这对于全球气象预报、台风/飓风监测和预警至关重要。
    
-   **物理与技术原理：**
    
    -   **布拉格共振散射 (Bragg Scattering)：** 当风吹过海面时，会产生微小的毛细波（波长在厘米级别）。海面风速越大，海面越粗糙，毛细波越多。散射计发射微波脉冲（其波长与海面毛细波波长相近），当微波打在这些毛细波上时，会发生布拉格共振后向散射。
        
    -   **风向反演：** 回波的强度不仅与风速有关（风越大，雷达截面积后向散射系数越大），还与雷达方位角和风向的夹角有关。因此，散射计通常设计有多个天线（如笔形波束圆锥扫描或扇形波束天线阵列），从不同角度对同一海域进行观测，通过复杂的地球物理模式函数（GMF），同时解算出风速和风向。
        
-   **代表卫星：** 欧洲的 MetOp系列 (ASCAT载荷)，中国的中法海洋卫星 (CFOSAT，搭载创新的扇形波束旋转扫描散射计)，海洋二号 (HY-2)。
    

## 三、大气与特殊探测载荷 (Atmospheric & Specialized Payloads)

除了对地表进行观测，还有一类专门用于探测地球大气成分和重力场的特种载荷。

### 1. 大气成分光谱探测仪 (Atmospheric Chemistry Spectrometers)

-   **功能：** 监测全球大气中的痕量气体分布（如臭氧 $O_3$、二氧化氮 $NO_2$、二氧化硫 $SO_2$、二氧化碳 $CO_2$、甲烷 $CH_4$ 等），用于温室气体排放监测、空气质量评估和臭氧层空洞监测。
    
-   **物理与技术原理：**
    
    -   **吸收光谱学：** 大气中的每种气体分子都会在特定的波长处吸收电磁波（这被称为气体的吸收光谱特征）。这些传感器测量穿过大气的太阳光或地表反射光。
        
    -   **多模式观测：** 包含“天底观测”（向下看，测量气柱总量）、“临边观测”（看向地球大气边缘，测量气体的垂直分布高度）和“掩星观测”（在太阳和地球之间，利用日出日落时光线穿过大气的信号进行极其精确的测量）。
        
    -   通过比对卫星接收到的光谱与太阳初始光谱的差异（即哪些波长的光被“吃掉”了），利用反演算法即可计算出污染物的浓度。
        
-   **代表卫星：** 欧洲的 Sentinel-5P (TROPOMI载荷，用于空气质量)，美国的 OCO-2 (温室气体)，中国的高分五号 (EMI载荷)。
    

### 2. 重力场测量仪 (Gravity Field Sensors)

-   **功能：** 极其精确地绘制全球重力场异常图。用于研究地球内部结构、洋流质量迁移、地下水储量变化以及极地冰川融化导致的质量流失。
    
-   **物理与技术原理：**
    
    -   **双星微波测距：** 典型的设计是两颗卫星在同一低地球轨道上一前一后相距几百公里飞行。当领先的卫星飞越地表质量较大的区域（如高山或高密度的地下矿藏）时，受到的引力微小增加，会加速前行，导致两星距离拉大；随后第二颗卫星飞越该区域时也会加速，两星距离缩小。
        
    -   通过 K 波段微波或极其精密的激光干涉仪，持续不断地测量这两颗卫星之间距离的微米级变化，即可反推出地球表面和内部的重力场/质量分布规律。
        
-   **代表卫星：** 美德合作的 GRACE (重力恢复和气候实验卫星) 及其后续星 GRACE-FO。
